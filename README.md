# Ozon Performance — отчёт по рекламе с юнит-экономикой

Плейбук для Google Colab: [`oz_performance_report.ipynb`](oz_performance_report.ipynb) выгружает статистику рекламы из **Ozon Performance API** и (опционально) данные магазина из **Ozon Seller API**, после чего собирает Excel в формате привычного отчёта по Wildberries.

Ноутбук **только читает** данные: он не запускает и не отключает кампании, не меняет бюджеты, ставки и цены.

## Листы отчёта

| Лист | Что показывает | Источник |
|---|---|---|
| Сводка | Итоги периода: расход, выручка, ДРР, вердикты по кампаниям, блок экономики | расчёт |
| Кампании | ДРР, CPO, CTR, вердикт по целевому ДРР + **предельный ДРР, запас в п.п., прибыль с рекламы, вердикт экономики** | Performance API |
| Товары | Статистика по SKU внутри кампаний (CPC и CPO), ставки, рекомендации | Performance API |
| Ключи | Поисковые фразы кампаний «Вывод в топ» с рекомендациями | Performance API |
| Воронка | Как в отчёте WB: переходы в карточку → корзины → заказы → выкупы по каждому SKU + вклад рекламы и ДРР по SKU | Seller API |
| Экономика | Юнит-экономика SKU: цена, комиссия, логистика, эквайринг, налог, себестоимость → маржа до рекламы, предельный ДРР/CPO, прибыль | Seller API + файл себестоимости |
| Диагностика | Появляется только при ошибках выгрузки или смене схемы данных Ozon | — |

## Два вопроса, на которые отвечает отчёт

1. **Эффективна ли кампания?** Лист «Кампании»: фактический ДРР против целевого (`TARGET_DRR`) — вердикты «Эффективна / Наблюдать / Неэффективна / Мало данных».
2. **Сходится ли реклама с экономикой?** Листы «Экономика» и «Кампании»: по каждому SKU считается маржа до рекламы и **предельный ДРР** — уровень ДРР, при котором кампания крутится ровно в ноль. Вердикты «В плюс / Около нуля / В минус» и расчётная прибыль в рублях.

## Методика предельного ДРР

Маржа до рекламы на одну проданную штуку:

```
маржа = средняя цена продажи (выручка рекламы ÷ заказы, иначе цена карточки)
      − комиссия Ozon (% от цены по схеме FBO/FBS, из v5/product/info/prices)
      − логистика (среднее магистрали + последняя миля)
      − эквайринг
      − налог (TAX_RATE_PCT × цена)
      − себестоимость (файл cost_prices.csv, иначе DEFAULT_COST_SHARE_PCT × цена)
      − EXTRA_COST_PER_UNIT (упаковка, обработка)
```

- **Предельный ДРР, %** = маржа ÷ цена × 100. Фактический ДРР ниже — реклама в плюс, выше — в минус.
- **Предельный CPO, ₽** = маржа — максимально допустимая цена заказа.
- **Прибыль с рекламы, ₽** = маржа × заказы − расход на рекламу.
- Для кампании предельный ДРР взвешивается по выручке её SKU; колонка «Покрытие экономикой %» показывает долю рекламной выручки с известной маржой.
- Порог `BREAKEVEN_SAFETY_PP` (по умолчанию 2 п.п.) задаёт коридор «Около нуля».

Ограничения: возвраты и невыкупы в маржу не включены; логистика и эквайринг — оценки Ozon для текущей цены, фактические удержания смотрите в финансовых отчётах.

## Настройка

1. Кабинет Ozon Seller → **Настройки → API-ключи → Performance API** → создайте сервисный аккаунт.
2. В Colab (панель слева → Секреты) добавьте `OZON_PERF_CLIENT_ID` и `OZON_PERF_CLIENT_SECRET`, включите доступ из блокнота.
3. *(Для воронки и экономики)* создайте ключ **Seller API** и добавьте секреты `OZON_SELLER_CLIENT_ID` и `OZON_SELLER_API_KEY`. Без них отчёт соберётся без листов «Воронка» и «Экономика».
4. *(Для точной экономики)* загрузите в сессию Colab файл `cost_prices.csv` (образец — [`cost_prices.example.csv`](cost_prices.example.csv)): колонки `артикул;себестоимость` или `sku;себестоимость`. Для SKU без строки в файле себестоимость берётся как `DEFAULT_COST_SHARE_PCT` от цены и помечается как допущение.
5. Задайте период и параметры в ячейке **Параметры** → **Среда выполнения → Выполнить все** → в конце скачается `.xlsx`.

## Параметры экономики

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `SALES_SCHEME` | `FBO` | Схема продаж для комиссии и логистики (`FBO`/`FBS`) |
| `TAX_RATE_PCT` | `6.0` | Налог с выручки (УСН «доходы»); 0 — не учитывать |
| `DEFAULT_COST_SHARE_PCT` | `30.0` | Себестоимость как % цены для SKU без строки в файле; 0 — не подставлять допущение |
| `EXTRA_COST_PER_UNIT` | `0.0` | Прочие затраты на штуку, ₽ |
| `BREAKEVEN_SAFETY_PP` | `2.0` | Коридор «около нуля» вокруг предельного ДРР, п.п. |
| `COST_FILE` | `cost_prices.csv` | Имя файла себестоимости в сессии Colab |

## Замечания по API

- Полный набор метрик воронки (`/v1/analytics/data`: переходы в карточку, корзины, выкупы, позиция) доступен на подписке **Premium Plus**; без неё ноутбук автоматически откатывается на базовые метрики (заказы и выручка).
- Асинхронные отчёты Performance API формируются последовательно из-за лимита одновременных выгрузок; период одной выгрузки — до 62 дней.
- Денежные значения ставок и бюджетов переводятся из миллионных долей рубля в рубли.
